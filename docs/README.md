# VGSR Research Documentation

This directory contains the authoritative research and development instructions for the VGSR project.

## Reading order

1. `00_PROJECT_CHARTER.md` — research purpose, scope, hypotheses
2. `01_RESEARCH_AGENDA.md` — milestones and experiment sequence
3. `02_METHOD_SPEC.md` — DRG, verifier, translation design
4. `03_EXPERIMENT_PROTOCOL.md` — baselines, experiments, metrics
5. `04_AGENT_INSTRUCTIONS.md` — instructions for AI coding agents
6. `05_CODING_STANDARDS.md` — implementation and research integrity rules
7. `06_DATA_SCHEMA.md` — internal data contracts
8. `07_EXPERIMENT_LOG_TEMPLATE.md` — reproducible experiment record

## Authority

When implementing research code, agents should treat these documents as the current project specification.

If implementation reality contradicts the research specification, do not silently resolve the conflict. Report it and request a decision.

## Important

These documents describe the current research plan. They are not proof of novelty or experimental results. Claims must be updated only after literature review and experiments establish them.
